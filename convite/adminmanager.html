Reset de acesso

Limpa o deviceToken dos convidados deste convite. Quem abriu noutro dispositivo poderá abrir novamente.

Reset de presentes

Remove reservas dos presentes, mas mantém a lista de presentes registada.

Limpar presentes

Elimina todos os presentes deste convite no MongoDB. Pode restaurar os presentes padrão depois.

Restaurar presentes padrão

Arquivar convite

Eliminar definitivamente

Apaga convite e dados relacionados do MongoDB. Não apaga a pasta no GitHub.

Importar convidados

Importação uniforme por ficheiro ou escrita manual, ligada ao convite escolhido.

Base de convidados

Formato recomendado:
Nome;Mesa;Acompanhantes;Telefone;Notas;Categoria;Número;Token antigo

Exemplo:
Prísca Daniel;A definir;0;;Nº 152;Single;152;rm-2026-152-prisca-daniel

Também aceita ficheiros com cabeçalho: nome, mesa, acompanhantes, telefone, notas, categoria, número, token antigo.
